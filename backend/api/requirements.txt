# EXACT PINS, and the shared entries must match backend/trader/requirements.txt
# exactly.

# This container runs trader scripts: `POST /jobs/{module}` executes
# `python -m scripts.<module>` with THIS interpreter. So `joblib`, `lightgbm`,
# `scikit-learn`, `numpy` and `pandas` are not incidental here — a model artifact
# written under one version and read under another either fails to load or, worse,
# loads and scores differently. They were floating or unconstrained on both sides,
# which made that divergence a matter of which day each image was built.
#
# `sqlalchemy` was also pinned to a *different* version here (2.0.35) than the
# trader floated to, while `backend/api/models/serving.py` is a hand-maintained
# mirror of `core/pg_writer.py` and `tests/test_orm_parity.py` compares the two
# column by column. Two ORM versions is a way for that mirror to drift.
